Not an LLM, but a small neural network: 230 examples, 141 words, 34 possible answers, 4,258 weights. The same principles, just small enough to see every number.
German input: kein = no – bier = beer – wein = wine – noch eins = one more

Step 1

Text becomes numbers

Every known word has its own column. If it occurs in the sentence there is a 1, otherwise a 0. The context counts like a word.

hallohibierweinkein[start][wein][bier]

Example: “kein bier” (no beer) in context [wein], eight of 141 columns shown, three of them with 1. Unknown words are ignored; before learning, “kein” would have been one of them.

bier

The word in the sentence

The guest has just said it, e.g. “kein bier”.

[bier]

The context (state of the conversation)

The guest has already ordered a beer. That is not in the sentence, e.g. for “noch eins” (one more).

For the network these are two separate columns with their own weights. It does not know that they belong together.

Weight

How strongly a word pushes this concept up (+) or holds it back (−). Every concept has its own weight for every word. It starts as a random number and is learned step by step during training.

Bias

The basic tendency of the concept, even if no word fits. It is a weight whose input is always 1. It starts at 0 and is learned during training as well.

Why tanh?

tanh squeezes z to −1 … +1. From about ±2 the concept is almost fully on or off. Without this bend, two layers would be just one matrix. The result h = tanh(z) = +0.96 (bottom left) goes into layer 2.

What do the numbers mean?

c11, c5, c2, c15 are four of the 24 concepts from layer 1 (you know c15 from slide 5). Activation h is their tanh result for “kein bier”: +1 means yes, −1 means no. The numbers below are the concept’s votes for the answer. “20 more” sums up the remaining concepts so that Σ adds up.

Example c2 → wein: weight −3.31 × activation −1.00 = vote +3.31 (minus times minus: c2 says “no”, and “no” speaks for wein)

Learning

Where do the concepts come from?

Start: randomness

W1 is the weight table of layer 1: 24 rows (concepts) × 141 columns (words). Every concept is one row in it, one number per word, and starts with different random numbers. If all started with the same value (for example 0), every concept would get exactly the same blame and the same changes during training. They would stay identical forever, 24 concepts would be just one. Only the random start makes them different.

Training shapes them

The examples push the rows. Specialists emerge, for example for “kein” + “bier”.

Names are interpretation

The network only knows “concept 15”. We read the meaning from the driving words.

The number of concepts determines how finely decisions can be graded: too few are too coarse, too many memorise the examples.

All of W2: 34 rows (answers) × 24 columns (concepts) = 816 numbers. b2: 34 numbers, one per answer.

W2

One row per answer, one column per concept. The number says how strongly this concept votes for this answer (+) or against it (−).

b2

The basic leaning of an answer that applies no matter which concepts fire. It is added to the sum of the votes.

Example wein

c2 has h = −1.00 and the weight −3.31 for wein. Vote: −3.31 × −1.00 = +3.31. All votes plus b2 (+0.11) give the score +11.4.

Words + context as 0/1

bier 1, [start] 1, “kein” unknown, ignored

Computers only calculate with numbers: every word gets a 1 (occurs) or a 0 (does not occur).

Layer 1

Words → concepts

h = tanh(W1·x + b1)

h = [ c18 −0.96, c20 −0.90, c1 +0.89, c17 +0.78, … ]

Concepts are yes/no questions about the sentence, e.g. “Does kein occur together with bier?” tanh turns the sum z into a clear signal from −1 (no) to +1 (yes). The result h goes into step 3.

3

Layer 2

Concepts → scores

s = W2·h + b2

s = [ bier +13.7, danke (thanks) +6.2, tschuess (bye) +5.0, … ]

Every possible answer collects the pros and cons of the questions and gets a score s from them. W2 and b2 are the learned weights, s is the result.

4

Softmax

Scores → percentages

p = softmax(s)

p = [ bier 99.9 %, danke (thanks) 0.1 %, … ]

The scores s become percentages p that add up to 100 %, like an election result.

5

Answer

Highest value wins

bier = 99.9 %

bier wins: wrong, should be wein

The answer with the highest percentage wins. Below 40 % the barkeeper asks back.

The network guesses for every sentence, measures the error and nudges the weights (slides 15 to 19). For “kein bier” training pulls the weights of “kein” so that they hold back bier votes and push wein votes.

Learning

What happens when you teach something?

Example: you teach „kein wein“ = bier.

1

The example is stored. An old one with the same context and sentence is replaced.

2

All weights are set to new random values (seed 0).

3

1500 rounds of training on all examples, old and new.

4

The new weights W1, b1, W2, b2 are written to the database.

Teaching: rare, takes longer

Everything is learned from scratch. The 24 concepts are created anew too: concept 5 from yesterday need not be the same question as concept 5 today.

Asking: often, milliseconds

Nothing is learned or stored. The weights are loaded and run forward once. The concepts are computed from the sentence.

Side effect: a new example can slightly change other answers too. A single „kein wein“ against 14 opposing „kein bier“ examples does not always win.

Learning

Training: guess, measure, improve

1

Guess

The network computes an answer for all 230 examples.

2

Measure the error

Guess minus correct answer: P − Y.

3

Distribute the blame

The error travels backwards to every weight (backpropagation).

4

Correct

Every weight takes a small step against its blame.

All of this 1500 times. Start: random numbers. End: weights that fit the examples.

Learning

The learning rule: how one weight moves

new weight = old weight − learning rate × error × input

Error

P − Y: how wrong was the answer? P = the network’s guess (0 to 1), Y = the right answer (1 = right, 0 = wrong). Positive = too strong, negative = too weak.

Input

Was the word in the sentence? 1 = correct it, 0 = the weight stays. For the bias the input is always 1.

Learning rate

Step size, here 0.5. Many small steps rather than one big jump.

Mini example: “kein bier” should give wein. One matrix, starting at 0, no momentum.

Loss

How unsure the network is about the right answer: −ln(P of the right answer), averaged over all 230 examples. 0 would mean completely sure.

Hits

Share of the training examples where the right answer is in front. These are known examples, not new sentences.

Why 1500 rounds?

After 100 rounds all examples are right. After that the network only gets surer: “kein bier” goes from 88 % to 99 % wein.

Learning

Backpropagation: the error flows backwards

Forward: guess

Words x

Concepts h

Answer p

Backward: blame

Blame of the W1 weights

Blame of the concepts

Error P − Y

What is it? The error at the output is distributed backwards, layer by layer, until every weight knows its share of the blame.

How? Every concept is asked: how much did you contribute to the wrong answer? After that every weight knows in which direction and how strongly it has to change.

D2 = P − Y   D1 = (D2 · W2) × (1 − h²)

Y = correct answer; P = guess; D2 = error at the output; h = activation of the concepts; W2 = layer 2 weights; D1 = blame of the concepts

Putting it in context

Why two layers?

A single matrix adds up independent word votes. “kein” and “bier” cannot work together, so “kein bier” would still vote for beer.

A concept can be learned so that it only fires when “kein” and “bier” occur together, and then votes for wine.

One matrix – 12 new sentences

8 / 12

Training: 223 / 230

Two layers – 12 new sentences

12 / 12

Training: 230 / 230

Test with 12 sentences the network has never seen (command “vergleich”, German for comparison). The single matrix fails on “bier bitte”, “wein bitte”, “ich will wein” and “heute ein wein”.

Putting it in context – mini example

Weight = points, bias = hurdle

Barkeeper: “Bier oder Wein?”

Guest saysgets
bierbier
weinwein
kein bierwein
kein weinbier

Only two choices (beer or wine): “kein” (no) flips the drink. The network does not know the question, it only sees these four examples.

Each of the words wein and kein brings 3 points. The bias is the hurdle: if the sum is above it, the concept is on.

0 words: 0│1.5│1 word: 3│4.5│2 words: 6

Points before the hurdle – the hurdles sit exactly in the middle

c0 = tanh(3·wein + 3·kein − 1.5)

−1.5 / +1.5 / +4.5

On from one word: OR

c1 = tanh(3·wein + 3·kein − 4.5)

−4.5 / −1.5 / +1.5

On only with both: AND

wein points = 2·c0 − 2·c1; bier points = 1

OR but not AND (= XOR): that is how “kein bier” becomes wein

Sentencec0c1wein→
bier−1.5−4.5+6.00wein ✗

kein bier+1.5−1.5+6.00wein ✓
kein wein+4.5+1.5+6.00wein ✗

wein = 1 if the word is in the sentence, otherwise 0. The same for kein. “3·wein” means: 3 points if wein occurs. c0 and c1 are the two switches from slide 23: c0 = OR (on from one word), c1 = AND (on only with both).

2·(3·wein + 3·kein − 1.5) − 2·(3·wein + 3·kein − 4.5) = 6  for every sentence

The word points (3·wein + 3·kein) appear in both brackets and drop out. What is left: 2·(−1.5) − 2·(−4.5) = −3 + 9 = 6. Also: wein points = 2·c0 − 2·c1, bier points always 1. That is why wein always wins.

Without tanh the words cancel out: two layers are then just one matrix. Only tanh turns the sums into switches (on/off), and only switches allow AND and OR.

What carries over

The principle stays the same: weighted sums, activation, softmax, measure the error, improve the weights. Only the input (embeddings and position) and the output (vocabulary instead of 34 answers) change.
