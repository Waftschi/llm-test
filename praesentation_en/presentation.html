Computers only calculate with numbers: every word gets a 1 (occurs) or a 0 (does not occur).

Layer 1

Words → concepts

h = tanh(W1·x + b1)

c18 −0.96 · c20 −0.90 · c1 +0.89 · c17 +0.78 …

Concepts are yes/no questions about the sentence, e.g. “Does kein occur together with bier?” tanh turns the sum z into a clear signal from −1 (no) to +1 (yes). The result h goes into step 3.

3

Layer 2

Concepts → scores

s = W2·h + b2

bier +13.7 · danke (thanks) +6.2 · tschuess (bye) +5.0 · …

Every possible answer collects the pros and cons of the questions and gets a score from them.

4

Softmax

Scores → percentages

p = softmax(s)

bier 99.9 % · danke (thanks) 0.1 % · …

The scores become percentages that add up to 100 %, like an election result.

5

Answer

Highest value wins

bier = 99.9 %

bier wins: wrong, should be wein

The answer with the highest percentage wins. Below 40 % the barkeeper asks back.

Weight

How strongly a word pushes this concept up (+) or holds it back (−). Every concept has its own weight for every word. It starts as a random number and is learned step by step during training.

Bias

The basic tendency of the concept, even if no word fits. It is a weight whose input is always 1. It starts at 0 and is learned during training as well.

Why tanh?

tanh squeezes z to −1 … +1. From about ±2 the concept is fully on or off. Without this bend, two layers would be just one matrix. The result h = tanh(z) = +1.00 (bottom left) goes into layer 2.

Learning in miniature

How “kein” is learned

1

Input

teach it in the console

The guest tells the barkeeper what would have been right: sentence, context and the correct answer.

2

Save

new row in examples

start | kein bier | wein

The example goes into the database next to the existing ones. It is the learning material; nothing in the network changes yet.

3

New column

word “kein” into the vocabulary

W1: column “kein”

Before, “kein” was unknown and ignored. Now it gets its own column in W1, with a random start for every concept.

4

Retrain

all examples, 1500 rounds

error → backprop

The network guesses for every sentence, measures the error and nudges the weights (slides 10 and 11). For “kein bier” training pulls the weights of “kein” so that they hold back bier votes and push wein votes.

5

Result

what was learned lives in the weights

bier 99.9 % → wein 98.9 %

“kein” is not an entry in a list; it lives in the numbers of W1 and W2. The sentence “kein bier” now gives wein.

Training: guess, measure, improve

1

Guess

The network computes an answer for all 230 examples.

2

Guess minus correct answer: P − Y.

3

The error travels backwards to every weight (backpropagation).

4

Correct

Every weight takes a small step against its blame.

All of this 1500 times. Start: random numbers. End: weights that fit the examples.

Backpropagation: the error flows backwards

Forward: guess

Words x

Concepts h

Answer p

Backward: blame

Blame of the W1 weights

Blame of the concepts

Error P − Y

What is it? The error at the output is distributed backwards, layer by layer, until every weight knows its share of the blame.

How? Every concept is asked: how much did you contribute to the wrong answer? After that every weight knows in which direction and how strongly it has to change.

D2 = P − Y D1 = (D2 · W2) × (1 − h²)

Y = correct answer · P = guess · D2 = error at the output · h = activation of the concepts · W2 = layer 2 weights · D1 = blame of the concepts

c0: 0.13·0.1 + (−0.74)·0.5 + 0.61·1.5 = +0.56

3 · × (1 − h²): how movable is the concept?

c0: h = +0.9 → 1 − 0.9² = 0.19 → 0.56 × 0.19 = 0.11
c1: h = −0.5 → 1 − 0.5² = 0.75 → 0.15 × 0.75 = 0.11

c0: activation +0.9 is close to the maximum +1: flat curve, small factor.

Learning

Where do the concepts come from?

Start: randomness

Every concept is a row in W1 and starts with different random numbers. If all started with the same value (for example 0), every concept would get exactly the same blame and the same changes during training. They would stay identical forever, 24 concepts would be just one. Only the random start makes them different.

Training shapes them

The examples push the rows. Specialists emerge, for example for “kein” + “bier”.

Names are interpretation

The network only knows “concept 15”. We read the meaning from the driving words.

The number of concepts determines how finely decisions can be graded: too few are too coarse, too many memorise the examples.

Putting it in context

Why two layers?

A single matrix adds up independent word votes. “kein” and “bier” cannot work together, so “kein bier” would still vote for beer.

A concept can be learned so that it only fires when “kein” and “bier” occur together, and then votes for wine.

One matrix · 12 new sentences

Training: 223 / 230

Two layers · 12 new sentences

12 / 12

Training: 230 / 230

Test with 12 sentences the network has never seen (command “vergleich”, German for comparison). The single matrix fails on “bier bitte”, “wein bitte”, “ich will wein” and “heute ein wein”.

What carries over

The principle stays the same: weighted sums, activation, softmax, measure the error, improve the weights. Only the input (embeddings and position) and the output (vocabulary instead of 34 answers) change.
