Putting it in context

Why two layers?

A single matrix adds up independent word votes. “kein” and “bier” cannot work together, so “kein bier” would still vote for beer.

A concept can be learned so that it only fires when “kein” and “bier” occur together, and then votes for wine.

12 / 12

Training: 230 / 230

Test with 12 sentences the network has never seen (command “vergleich”, German for comparison). The single matrix fails on “bier bitte”, “wein bitte”, “ich will wein” and “heute ein wein”.

This is the reason for the hidden layer. Without it the network cannot represent combinations such as “kein” plus “bier” cleanly. The big numbers are the meaningful test: twelve sentences that appeared in no training example, for instance “kein bier bitte” or “ich will wein”. The single matrix gets eight of them right, two layers get all twelve. The small numbers below are only the training examples: there the matrix reaches 223 of 230, two layers 230 of 230. That only shows how well the network can represent the examples. Whether it also works on new sentences only the test shows. All numbers come from the command vergleich in the current model and change with the data. The test sentences are fixed in the code and there are only twelve, so the number is a hint and not a proof.
