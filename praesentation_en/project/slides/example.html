Not an LLM, but a small neural network: 230 examples, 141 words, 34 possible answers, 4,258 weights. The same principles, just small enough to see every number.
German input: kein = no · bier = beer · wein = wine · noch eins = one more

On the left an example of learning: without any example for “kein” (no), the barkeeper only recognises the word “bier” (beer) and wrongly answers bier. Only after we teach it “kein bier = wein” does it answer wein (wine) correctly. The barkeeper gets a sentence and the context, meaning what has been ordered so far. The same sentence “noch eins” (one more) means different things depending on context: after a beer it means another beer, at the start it means “you have not ordered anything yet” (the answer nichts_bestellt). Important to say: this is not an LLM, but it uses the same building blocks. The numbers come from the current model and change when you teach new examples.
