Summary – before learning

How an answer comes about

Example “kein bier” (no beer) in context [start], before learning. Blue: the values handed from step to step.

1

Text → numbers

Words + context as 0/1

x = 0 0 1 1 0 … 1

bier 1, [start] 1, “kein” unknown, ignored

Computers only calculate with numbers: every word gets a 1 (occurs) or a 0 (does not occur).

2

Layer 1

Words → concepts

h = tanh(W1·x + b1)

h = [ c18 −0.96, c20 −0.90, c1 +0.89, c17 +0.78, … ]

Concepts are yes/no questions about the sentence, e.g. “Does kein occur together with bier?” tanh turns the sum z into a clear signal from −1 (no) to +1 (yes). The result h goes into step 3.

3

Layer 2

Concepts → scores

s = W2·h + b2

s = [ bier +13.7, danke (thanks) +6.2, tschuess (bye) +5.0, … ]

Every possible answer collects the pros and cons of the questions and gets a score s from them. W2 and b2 are the learned weights, s is the result.

4

Softmax

Scores → percentages

p = softmax(s)

p = [ bier 99.9 %, danke (thanks) 0.1 %, … ]

The scores s become percentages p that add up to 100 %, like an election result.

5

Answer

Highest value wins

bier = 99.9 %

bier wins: wrong, should be wein

The answer with the highest percentage wins. Below 40 % the barkeeper asks back.

This is the whole forward path in five steps; the right-hand column explains each step in plain words. The blue lines show which values are handed from step to step, here using “kein bier” in the state before learning. The network does not know “kein” yet, ignores it and only sees “bier” with [start]. It answers bier with 99.9 percent and is wrong. After learning the calculation steps are exactly the same, only the weights change. The numbers come from a model that was trained without the kein examples. The most important step is step 2: a concept is not a hard-coded rule but a kind of yes/no question about the sentence, for example “does kein occur together with bier?”. The network does not know the question in words, it only has numbers that react strongly to exactly this word combination. Training decides which questions are worth asking. With tanh the values of the concepts are squeezed to between −1 and +1: near +1 means yes, near −1 means no, around 0 undecided. That is also why we need tanh: without this bend, layer 2 times layer 1 would mathematically be just one single matrix, and the network could not learn combinations such as kein plus bier (see slides 22 to 24). The result of tanh is called h, and it is the value used in step 3. A concrete example with tanh(+1.96) = +0.96 is on slide 5. W1, W2, b1 and b2 are the weights, the numbers that are learned during training.
