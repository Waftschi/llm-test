Where do the concepts come from?

Start: randomness

Every concept is a row in W1 and starts with different random numbers. If all started with the same value (for example 0), every concept would get exactly the same blame and the same changes during training. They would stay identical forever, 24 concepts would be just one. Only the random start makes them different.

Training shapes them

The examples push the rows. Specialists emerge, for example for “kein” + “bier”.

Names are interpretation

The network only knows “concept 15”. We read the meaning from the driving words.

The number of concepts determines how finely decisions can be graded: too few are too coarse, too many memorise the examples.

Nobody programs the concepts. We only fix how many there are, 24 in our case, and the activation function tanh. Everything else emerges during training. You can think of every concept as a soft yes/no question about the sentence. With n concepts the network can distinguish up to 2 to the power of n different combinations. About the randomness: if all concepts start the same, they see the same inputs and get the same blame. They then always change the same way and stay identical copies. Randomness breaks this symmetry: every concept starts at a different place and therefore becomes a different specialist. In our code: np.random.seed(0), random numbers times 0.5. The same happens in real LLMs, only with billions of weights.
