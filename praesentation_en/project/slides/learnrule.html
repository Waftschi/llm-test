Learning

The learning rule: how one weight moves

new weight = old weight − learning rate × error × input

Error

P − Y: how wrong was the answer? P = the network’s guess (0 to 1), Y = the right answer (1 = right, 0 = wrong). Positive = too strong, negative = too weak.

Input

Was the word in the sentence? 1 = correct it, 0 = the weight stays. For the bias the input is always 1.

Learning rate

Step size, here 0.5. Many small steps rather than one big jump.

Mini example: “kein bier” should give wein. One matrix, starting at 0, no momentum.

Round 1: 0 − 0.5 × (−0.50) × 1 = +0.25

Minus times minus: wein was too weak, so its weight goes up. The closer to the goal, the smaller the error and the smaller the step.

This is the one rule by which every single weight in the network learns, and every bias too. It has three ingredients. The error says how wrong the answer was: positive means too strong, negative too weak. The input says whether the word was in the sentence at all: only then can its weight be to blame, otherwise the input is 0 and the weight stays as it is. For the bias the input is always 1, so it learns along with every example. The learning rate sets the step size. On the right is a tiny example with a single matrix: all weights start at 0, so the network says 50 to 50. Wein is 0.5 too weak, the error is minus 0.5. Minus the learning rate times minus 0.5 times 1 gives plus 0.25, so the weight goes up. Round by round wein becomes more likely, the error gets smaller and so does the step: learning slows itself down as it approaches the goal. Important: this one sentence also pushes the word bier towards wein. Only the example bier equals bier pushes it back. That is why we need many different examples, and why the steps are averaged over all of them. To keep the terms apart: weights and biases are what is learned, this rule is the learning. The real barkeeper adds momentum, and with two layers the error for layer 1 first has to be computed by backpropagation, which the next slides show.
