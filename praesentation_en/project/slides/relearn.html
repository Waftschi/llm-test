Learning

What happens when you teach something?

Example: you teach „kein wein“ = bier.

1

The example is stored. An old one with the same context and sentence is replaced.

2

All weights are set to new random values (seed 0).

3

1500 rounds of training on all examples, old and new.

4

The new weights W1, b1, W2, b2 are written to the database.

Teaching: rare, takes longer

Everything is learned from scratch. The 24 concepts are created anew too: concept 5 from yesterday need not be the same question as concept 5 today.

Asking: often, milliseconds

Nothing is learned or stored. The weights are loaded and run forward once. The concepts are computed from the sentence.

Side effect: a new example can slightly change other answers too. A single „kein wein“ against 14 opposing „kein bier“ examples does not always win.

This is the difference between teaching and asking. Teaching retrains the whole model from scratch, with the same random start values and all examples. So after learning the concepts are not the old ones with a correction but a new set of yes/no questions. Asking only loads the stored weights and runs forward once, which takes milliseconds, and the concepts exist only as the intermediate result h. If you teach kein wein equals bier, the network has to tell kein bier from kein wein. That needs concepts that combine kein with each drink, which is exactly what tanh in layer 1 enables. Whether it works depends on how many similar examples there are: a single example against fourteen opposing ones struggles to win. The alternative, training only a few steps on the new example, would be faster, but the network would forget old things (catastrophic forgetting).
