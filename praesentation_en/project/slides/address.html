Which weight changes?

Change of W[i, j] = error at output i × value of input j

Example: weight W2[bier, c0], activation of c0 = +1.00, learning rate 0.5, momentum 0.9

RoundP(bier)Error P−YStep (momentum)
10.30−0.70+0.350
20.50−0.50+0.565
  • Error negative and concept active: the weight goes up.
  • Input = 0 (word not in the sentence): change exactly 0.
This is the answer to the question how the error finds the right place in the matrix. Every weight has an address made of output and input. It only changes if the error arrives at its output and its input was active. For words that do not occur in the sentence, the input is 0, so the weight stays untouched. The step comes from 0.9 times the previous step minus 0.5 times the gradient: round 1 gives 0.35, round 2 gives 0.9 times 0.35 plus 0.25, which is 0.565. In reality the gradient is averaged over all 230 examples; here it is only one example for illustration.
