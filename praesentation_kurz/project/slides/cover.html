Barkeeper in
25 Minuten

Wie ein kleines neuronales Netz aus einem Satz eine Antwort macht und aus Fehlern lernt

Teamvortrag

Der Barkeeper ist kein Sprachmodell, sondern ein kleines neuronales Netz mit 4.258 Zahlen. Es nutzt dieselben Bausteine wie ein LLM, ist aber so klein, dass man jeden Schritt sehen kann. In rund 25 Minuten zeigen wir, wie aus einem Satz eine Antwort wird, wie das Netz lernt und wie sich das von einem LLM unterscheidet.
