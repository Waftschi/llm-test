Barkeeper in
25 minutes

How a small neural network turns a sentence into an answer and learns from mistakes

Team talk

The barkeeper is not a language model but a small neural network with 4,258 numbers. It uses the same building blocks as an LLM, but it is small enough to see every step. In about 25 minutes we show how a sentence becomes an answer, how the network learns and how that differs from an LLM.
