Learning

What happens when you teach something?

Example: you teach “kein wein” = bier.

1

The example is stored. An old one with the same context and sentence is replaced.

2

All weights are set to new random values (seed 0).

3

1,500 rounds of training on all examples, old and new.

4

The new weights W1, b1, W2, b2 are written to the database.

Teaching: rare, takes longer

Everything is learned from scratch. The 24 concepts are created anew too.

Asking: often, milliseconds

Nothing is learned. The weights are loaded and run forward once.

Side effect: a new example can slightly change other answers too.

When teaching, the whole model is trained from scratch, with the same random start values and all examples. So afterwards the concepts are not the old ones with a correction but a new set of yes/no questions. When asking, only the stored weights are loaded, which takes milliseconds. Learning faster with only the new example would forget old things.
