Part 1 – Overview

How an answer comes about

Example: “kein bier” in the context [wein]. The next slides go through each step.

1

Text → numbers

x = 0 0 1 1 0 … 1

Each word is 1 (occurs) or 0

2

Layer 1: words → concepts

h = tanh(W1·x + b1)

24 yes/no questions about the sentence

3

Layer 2: concepts → scores

s = W2·h + b2

Each concept votes for or against each answer

4

Softmax: scores → percentages

p = softmax(s)

Adds up to 100 %

5

Answer

wein 98.9 %

Highest value wins

This is the whole forward path in five steps. W1, b1, W2 and b2 are the learned numbers. The next slides show every step with the real numbers of the model.
