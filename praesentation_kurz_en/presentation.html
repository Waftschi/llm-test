141 columns, almost all 0. The context ([wein]) counts like a word.

Why numbers?

A computer only calculates with numbers. Every known word gets a 1 if it is in the sentence, otherwise a 0.

Unknown words

They are ignored. If more than half are unknown, the barkeeper asks back.

Learning

Training: guess, measure, nudge

1

Guess

The network computes an answer for all 230 examples.

2

Measure the error

Guess minus right answer: P − Y.

3

Distribute the blame

The error travels backwards to every weight (backpropagation).

4

Nudge

Every weight takes a small step against its blame.

new weight = old weight − learning rate × error × input

All of this 1,500 times. Start: random numbers. End: weights that fit the examples. Input = 1 if the word was in the sentence, otherwise 0.

Why 1,500 rounds?

After 100 rounds all examples are right. After that the network only gets surer: “kein bier” goes from 88 % to 99 % wein.

Learning

What happens when you teach something?

Example: you teach “kein wein” = bier.

1

The example is stored. An old one with the same context and sentence is replaced.

2

All weights are set to new random values (seed 0).

3

1,500 rounds of training on all examples, old and new.

4

The new weights W1, b1, W2, b2 are written to the database.

Teaching: rare, takes longer

Everything is learned from scratch. The 24 concepts are created anew too.

Asking: often, milliseconds

Nothing is learned. The weights are loaded and run forward once.

Side effect: a new example can slightly change other answers too.

Context

Why two layers?

One matrix

It only adds single-word votes. “kein” and “bier” cannot team up, so “kein bier” still votes for bier.

Two layers

A concept can fire only when kein and bier occur together, and then vote for wein.

tanh

Without tanh two layers would be mathematically just one matrix. Only tanh turns sums into switches, and switches allow AND and OR.
